# Tournament Ranking

เว็บสำหรับเก็บสถิติและจัดอันดับ (Ranking) ทีมและผู้เล่นที่ลงแข่งทัวร์นาเมนต์ พร้อม API สำหรับเชื่อมกับเว็บไซต์อื่น

A website for tournament results, team and player rankings, with an API-key–protected REST API so other websites can use the data.

| ส่วน | เทคโนโลยี | ที่อยู่ตอนรันในเครื่อง |
| --- | --- | --- |
| Frontend (`apps/web`) | Next.js 16, React 19, TypeScript, ฟอนต์ IBM Plex Sans Thai Looped, ธีมขาว แดง ดำ | http://localhost:3000 |
| Backend (`apps/api`) | Node.js, Express 5, TypeScript, Prisma, SQLite | http://localhost:4000 |
| บอท Discord (`apps/bot`) | discord.js 14 | ใน Discord ของคุณ |
| เอกสาร API | OpenAPI 3 + Swagger UI | http://localhost:4000/docs |

## เริ่มใช้งาน

ต้องมี Node.js 22 ขึ้นไป

```bash
npm install
npm run setup   # สร้างฐานข้อมูล, API key ของเว็บและบอท, รหัสผ่านผู้ดูแล และข้อมูลตัวอย่าง
npm run dev     # เปิด API เว็บ และบอทพร้อมกัน (บอทจะรอจนกว่าจะใส่ DISCORD_TOKEN)
```

บน Windows ครั้งต่อไปดับเบิลคลิก **`start-webranking.bat`** ในโฟลเดอร์โปรเจกต์ได้เลย (หรือคลิกขวา → Send to → Desktop เพื่อสร้าง shortcut ไว้บนหน้าจอ)

`npm run setup` จะพิมพ์ **รหัสผ่านผู้ดูแล** และ **ลิงก์ลับของหน้าเข้าสู่ระบบ** เช่น `http://localhost:3000/admin-3f9c2a7b1d` ออกมา (ทั้งสองอย่างเก็บไว้ใน `apps/web/.env.local` ชื่อ `ADMIN_PASSWORD` และ `ADMIN_PATH`) เก็บลิงก์นี้ไว้คนเดียว

หน้าเว็บทั่วไปไม่มีปุ่มเข้าหลังบ้าน ถ้ายังไม่ได้ล็อกอิน `/admin` จะขึ้นว่า "ไม่พบหน้านี้" เหมือนไม่มีหลังบ้านอยู่ เปลี่ยนลิงก์ลับได้โดยแก้ `ADMIN_PATH` แล้วเปิดเว็บใหม่ ถ้าลบค่านี้ออก หน้าเข้าสู่ระบบจะกลับไปอยู่ที่ `/admin/login`

ไม่อยากได้ข้อมูลตัวอย่าง: `npm run setup -- --no-demo` บนฐานข้อมูลว่าง

## ใช้งานอะไรได้บ้าง

**หน้าสาธารณะ**
- **Ranking ผู้เล่นแบบ MMR** (`/rankings/players`): ทุกคนเริ่มที่ 1000 ชนะขึ้น แพ้ลง ชนะทีมที่เก่งกว่าได้มากกว่า (K 32, สามแมตช์แรกเป็นแมตช์จัดอันดับ K 48) โบนัส MVP +2 / SVP +1 ต่อเกม มีโพเดียม Top 3 แรงค์ 7 ระดับ (Bronze, Silver, Gold, Platinum, Diamond, Master, Legend) ฟอร์ม 5 แมตช์ และ ▲▼ อันดับที่ขยับใน 7 วัน
- Ranking ทีม (MMR ทีมแบบ Elo เริ่มที่ 1000) และหน้าสถิติผู้เล่น (`/rankings/stats` เรียงตามแต้ม, แต้มเฉลี่ย, เรตติ้ง, MVP ฯลฯ)
- **UID คือตัวตนของผู้เล่น**: เปลี่ยนชื่อในเกมได้ ถ้า UID (+ Server) เดิม สถิติและ MMR ยังเป็นของคนเดิม ชื่อเก่าเก็บไว้ในประวัติ สกอร์บอร์ดเก่าที่ใช้ชื่อเก่าก็ยังนับให้ถูกคน ถ้ามีคนเดียวกันถูกบันทึกเป็นสองคน ใช้ "รวมผู้เล่นที่ซ้ำ" ในหน้าแก้ไขผู้เล่น
- หน้าทีม ผู้เล่น ทัวร์นาเมนต์ (ตารางคะแนน ชนะ 3 เสมอ 1) และผลการแข่งแต่ละซีรีส์ พร้อมสกอร์บอร์ดทุกเกม (PTS REB BLK STL AST LBR, เรตติ้ง, MVP/SVP)
- ช่องค้นหาพร้อมปุ่มค้นหาทุกหน้า และ dropdown เลือกทีมที่พิมพ์ค้นหาได้

**หน้าจัดการ (`/admin`)**
- แดชบอร์ดพร้อมเมนูด้านข้าง: การ์ดสรุปทีม ผู้เล่น แมตช์ 7 วัน ทัวร์ที่กำลังแข่ง, กราฟแมตช์ต่อวัน, ผู้เล่นแต่ละแรงค์, Top 5 MMR และ **งานที่รอทำ** (แมตช์ในสายที่รอผล, การโต้แย้งผล, ทัวร์ที่เปิดรับสมัคร, ผู้เล่นที่ยังไม่มี UID, ทีมที่ยังไม่มีโลโก้)
- หน้ารายการผลการแข่ง ทัวร์นาเมนต์ ทีม ผู้เล่น เป็นตาราง กรองและค้นหาได้ กดแก้ไขหรือลบได้จากแถวเลย
- เพิ่ม/แก้/ลบ ทีม ผู้เล่น ทัวร์นาเมนต์ และผลการแข่ง
- ทุกช่องรูป (โลโก้ทีม, รูปผู้เล่น, ภาพผลการแข่ง) **ลากรูปมาวาง, วางด้วย Ctrl+V หรือคลิกเลือกไฟล์ได้**
- บันทึกผลการแข่งเป็นซีรีส์ (เช่น Bo3) กรอกสกอร์บอร์ดทีละเกม พิมพ์ชื่อทีมหรือผู้เล่นใหม่ได้เลย ระบบสร้างให้ตอนบันทึก
- **อ่านผลจากข้อความผลและรูปสกอร์บอร์ดหลายรูป** แล้วกรอกฟอร์มให้ ระบบจะไม่บันทึกเองจนกว่าจะกดยืนยัน
  - **ฟรี ไม่ต้องตั้งอะไร:** ระบบอ่านตัวเลขในเครื่อง (OCR) อ่านหน้า MATCH HISTORY ทั้งหน้า ได้สถิติ 6 ช่อง ชื่อ เรตติ้ง MVP/SVP และสกอร์ (รวม PTS ของแต่ละฝั่ง) ใช้เวลาราว 3 วินาทีต่อรูป รูปเล็กหรือไม่ชัดจะเว้นช่องว่างไว้ให้กรอกเองแทนการเดา
  - **แม่นกว่าด้วย AI (เสียเงิน):** ใส่ `ANTHROPIC_API_KEY` ใน `apps/api/.env` แล้วระบบจะใช้ Claude อ่านแทน
- สร้าง/ยกเลิก API key สำหรับเว็บอื่น

## ผู้เล่นเข้าสู่ระบบด้วย Discord

ผู้เล่นกด **เข้าสู่ระบบ** ที่เมนู (หน้า `/me`) แล้วล็อกอินด้วย Discord ได้เลย ไม่ต้องสมัครหรือตั้งรหัส ทำได้ 3 อย่าง:
- **ผูกโปรไฟล์ด้วย UID:** ถ้ามีผู้เล่น UID นี้อยู่แล้ว สถิติและ MMR เดิมจะตามมาทั้งหมด ถ้ายังไม่มี ใส่ชื่อในเกมเพื่อสร้างใหม่ บัญชีเดียวผูกได้หลายตัวละคร
- **แก้โปรไฟล์ของตัวเอง:** รูป ชื่อเล่น ตำแหน่ง และประเทศ ส่วนชื่อในเกม ทีม และสถิติ ยังมาจากผลการแข่งและบอทเหมือนเดิม
- **เชื่อมกับบอทให้เอง:** คนที่บอทใส่ไว้ในรายชื่อทีม (`/register`, `/roster`) ล็อกอินครั้งแรกก็เห็นโปรไฟล์ตัวเองทันที

หน้าโปรไฟล์ที่ผูกแล้วจะมีป้าย **✓ ยืนยันผ่าน Discord** ถ้ามีคนผูก UID ผิด ผู้จัดกด **ยกเลิกการผูก** ได้ที่หน้าแก้ไขผู้เล่นในหลังบ้าน หลังบ้านยังใช้ลิงก์ลับกับรหัสผ่านของผู้จัดแยกต่างหาก

วิธีเปิดใช้ (ครั้งเดียว):
1. เข้า https://discord.com/developers/applications เลือกแอปเดียวกับบอท → เมนู **OAuth2**
2. ก๊อป **Client ID** และกด **Reset Secret** เพื่อเอา **Client Secret**
3. ที่ **Redirects** กด Add แล้วใส่ `https://therankingovertime.com/api/auth/discord/callback` (ถ้าทดสอบในเครื่องใส่ `http://localhost:3000/api/auth/discord/callback` เพิ่มอีกบรรทัด)
4. ใส่ใน `apps/web/.env.local`: `DISCORD_CLIENT_ID=...`, `DISCORD_CLIENT_SECRET=...` และ `PUBLIC_SITE_URL=https://therankingovertime.com` แล้วเปิดเว็บใหม่

ถ้ายังไม่ใส่ค่าเหล่านี้ เว็บจะไม่แสดงปุ่มเข้าสู่ระบบเลย

## แยกเกม และทีมที่ผู้เล่นจัดการเอง

**เกม:** ผู้เล่น (หนึ่งตัวละคร = หนึ่ง UID) ทีม และทัวร์นาเมนต์ อยู่ในเกมใดเกมหนึ่ง MMR แรงค์ และอันดับจึงแยกตามเกม ถ้าคนเดียวเล่นหลายเกม ให้ผูกตัวละครของแต่ละเกมกับ Discord บัญชีเดียวกัน
- หลังบ้าน > **เกม** เพิ่ม เปลี่ยนชื่อ หรือลบเกม (ลบได้เมื่อยังไม่มีใครใช้) หรือพิมพ์ชื่อเกมใหม่ตอนสร้างทัวร์ก็ได้
- ทีมและผู้เล่นที่ลงแข่งในทัวร์จะเข้าเกมของทัวร์นั้นให้เอง ถ้ามีเกมเดียว ทุกคนอยู่เกมนั้น
- เมื่อมีตั้งแต่ 2 เกม หน้า Ranking จะมีแท็บเลือกเกม (จำเกมที่เลือกไว้ให้)

**ทีม (หน้า `/me`):** ผู้เล่นที่ล็อกอินด้วย Discord ทำเองได้
- **สร้างทีม** ด้วยตัวละครที่ยังไม่มีทีม คนสร้างเป็นหัวหน้า 👑 และได้ **ลิงก์เชิญ** (`/join/<รหัส>`) ส่งให้เพื่อน เพื่อนเปิดลิงก์ ล็อกอิน แล้วกดเข้าร่วม หรือวางรหัสในช่อง "เข้าร่วมทีม"
- **ออกจากทีม** เองได้ ถ้าหัวหน้าออก ตำแหน่งหัวหน้าจะส่งต่อให้สมาชิกคนอื่นให้อัตโนมัติ
- หัวหน้า **เตะสมาชิก** ส่งต่อตำแหน่งหัวหน้า และสร้างลิงก์เชิญใหม่ (ลิงก์เก่าใช้ไม่ได้) ได้
- ทีมละไม่เกิน 15 คน และเข้าได้เฉพาะทีมของเกมเดียวกับตัวละคร
- หน้า `/me` แสดงแรงค์ MMR และ **อันดับในแต่ละเกม** ของทุกตัวละคร

ผู้จัดตั้งหัวหน้าทีมและดูลิงก์เชิญของทีมไหนก็ได้ที่หลังบ้าน > ทีม > แก้ไข

## กิลด์ (คลับ)

กิลด์คือสังกัดของผู้เล่นที่แยกจากทีมแข่ง ตัวละครหนึ่งตัวอยู่ได้ 1 กิลด์ และยังอยู่ทีมของตัวเองได้ตามเดิม

- **สร้าง:** ผู้เล่นคนไหนก็สร้างกิลด์ได้ที่หน้า "โปรไฟล์ของฉัน" (`/me`) คนสร้างได้เป็นหัวหน้ากิลด์
- **เชิญ:** เชิญได้เฉพาะหัวหน้า โดยใส่ UID ในเกมของคนที่จะชวน คนที่ถูกเชิญต้องกดรับเองที่ `/me` ไม่มีลิงก์ที่ใครก็กดเข้าได้
- **หัวหน้า:** เตะสมาชิก แก้ชื่อ โลโก้ และคำอธิบาย และยกตำแหน่งหัวหน้าให้คนอื่นได้ ถ้าหัวหน้าออกเอง สมาชิกที่ MMR สูงสุดได้เป็นหัวหน้าแทน ถ้าสมาชิกคนสุดท้ายออก กิลด์จะปิด
- **จำนวนสมาชิก:** รับได้ 200 คน ผู้จัดเพิ่มได้ที่ หลังบ้าน > กิลด์ ซึ่งเป็นที่เดียวกับที่ใช้เปลี่ยนหัวหน้า (เช่น หัวหน้าเข้าบัญชีไม่ได้) นำสมาชิกออก และลบกิลด์
- **หน้ากิลด์ (`/guilds`):** ทุกคนดูรายชื่อสมาชิกได้ เรียงอันดับในกิลด์ตาม MMR โดยนับเฉพาะคนที่ลงแข่งแล้ว และโชว์อันดับ 1 ของกิลด์ไว้ด้านบน
- **อันดับกิลด์:** คะแนนกิลด์คือ MMR เฉลี่ยของสมาชิก 5 คนที่เก่งที่สุดที่ลงแข่งแล้ว กิลด์อันดับ 1 และผู้เล่นอันดับ 1 ของกิลด์นั้นโชว์ที่หน้าแรกเสมอ

## ทัวร์ลงเดี่ยว (สุ่มจัดทีม)

สำหรับทัวร์ที่ผู้เล่นสมัครคนเดียว แล้วให้ระบบจัดทีมให้
1. หลังบ้าน > สร้างทัวร์ เลือกรูปแบบการแข่ง แล้วตั้ง **การสมัคร: ลงเดี่ยว แล้วระบบสุ่มจัดทีม** ใส่จำนวนคนต่อทีม (ปกติ 3) แล้วติ๊ก **เปิดรับลงทะเบียนเดี่ยว** แรงค์ในเกมตั้งที่หลังบ้าน > **เกม** > ปุ่ม **แรงค์** (ชื่อ + รูปไอคอน เรียงจากต่ำไปสูง ค่าเริ่มต้นคือแรงค์ของ Kuroko: แม่ทัพไร้มงกุฎ, ซูเปอร์สตาร์ ม.ปลาย, รุ่นแห่งปาฏิหาริย์, เจ้าแห่ง ZONE)
2. ผู้เล่นเปิดหน้าทัวร์ ล็อกอินด้วย Discord แล้วเลือกตัวละคร **ตำแหน่ง** (Guard, Forward, Center หรือ All Around ที่เล่นได้ทุกตำแหน่ง) และ **แรงค์ในเกมตอนนี้** จากนั้นกดลงทะเบียน จะแก้หรือถอนชื่อก็ได้จนกว่าผู้จัดจะสุ่มทีม
3. ผู้จัดกด **🎲 สุ่มทีม** ในหน้าแก้ไขทัวร์ ระบบจะคละให้แรงค์รวมของแต่ละทีมใกล้เคียงกัน และให้ทุกทีมมี Guard, Forward, Center ครบ (All Around แทนได้ทุกตำแหน่ง) ถ้าจำนวนคนหารไม่ลงตัว คนที่ลงทะเบียนหลังสุดจะเป็นตัวสำรอง กดสุ่มใหม่ได้จนพอใจ แล้วกด **ยืนยันทีมชุดนี้**
4. ทีมที่ได้จะลงทัวร์พร้อมรายชื่อผู้เล่น (คนแรกในทีมเป็นหัวหน้าใน Discord) จากนั้นจัดสายและแข่งได้ตามปกติ ผู้เล่นยังอยู่ทีมเดิมของตัวเอง สถิติจากทัวร์นี้นับให้ถูกคน

## Blacklist

- ทีมที่แพ้บายในสายการแข่งเพราะไม่มาเช็คอินภายในเวลาแข่ง (รวมเวลาเลท) ผู้เล่นทุกคนในรายชื่อทีมจะติด Blacklist และถูกหัก **20 MMR** ต่อครั้งโดยอัตโนมัติ ทั้งเมื่อทีมคู่แข่งกดขอชนะบาย และเมื่อผู้จัดตัดสินให้ (ถ้าทีมไม่ได้ส่งรายชื่อ จะนับผู้เล่นที่อยู่ในทีมตอนนั้น)
- ถ้าผู้จัดเปลี่ยนผลหรือยกเลิกผลของแมตช์นั้น รายชื่อจะหายและคืน MMR เอง
- หน้า `/blacklist` แสดงรายชื่อที่ยังมีผล หน้าผู้เล่นมีป้าย ⛔ และสาเหตุ ใน Ranking ผู้เล่นมี ⛔ ข้างชื่อ
- หลังบ้าน > Blacklist: แก้จำนวน MMR ที่หัก (เช่น เหตุสุดวิสัย ใส่ 0) ยกเลิกโทษ (คืน MMR) ใส่โทษกลับ หรือเพิ่มผู้เล่นเองพร้อมสาเหตุและจำนวน MMR ที่หัก
- Discord: บอทบอกรายชื่อที่ติด Blacklist ในประกาศผลและในห้องแข่ง และมีคำสั่ง `/blacklist list` (ทุกคน), `/blacklist add`, `/blacklist penalty` และ `/blacklist lift` (ผู้จัด)

## โฆษณาร้าน

หลังบ้าน > **โฆษณาร้าน** ลงรูปโฆษณาร้านได้ 3 ตำแหน่ง:

- **แถบใต้เมนู** แสดงทุกหน้า (แนะนำรูป 1200×200 px และรูปมือถือ 800×300 px) ถ้ามีหลายอันจะสลับกันทุก 7 วินาที
- **การ์ดหน้าแรก** ใต้ตัวเลขสรุป สูงสุด 3 ใบ (แนะนำ 1200×675 px)
- **ป๊อปอัป** เด้งวันละครั้งต่อคน กดปิดได้ (แนะนำ 800×1000 px)

ตั้งวันเริ่ม/หยุดแสดง เปิด/ปิดได้จากรายการ และดูยอดคลิกได้ ลิงก์ทุกอันผ่าน `/go/ad/<id>` เพื่อนับคลิกก่อนพาไปร้าน โฆษณาไม่แสดงในหลังบ้าน

## บอท Discord: ดึงผลจากห้องส่งผล

คนส่งผลโพสต์ข้อความ เช่น `WD 2-0 มาช้าแต่ทันไหม` พร้อมรูปสกอร์บอร์ดทุกเกม บอทจะอ่านแล้วตอบกลับเป็นสรุปให้ตรวจ แอดมินกด **✅ บันทึก** (หรือกด ✅ ที่โพสต์ต้นทาง) ผลจึงเข้าเว็บ ทีมหรือผู้เล่นที่ยังไม่มีจะถูกสร้างให้อัตโนมัติ โพสต์เดิมบันทึกซ้ำไม่ได้

1. สร้างแอปที่ https://discord.com/developers/applications → เมนู **Bot** กด **Reset Token** แล้วเปิด **Message Content Intent**
2. เชิญบอทเข้าเซิร์ฟเวอร์ (OAuth2 → scope `bot` + `applications.commands` สิทธิ์ View Channels, Send Messages, Embed Links, Read Message History, Add Reactions)
3. เปิด `apps/bot/.env` (สร้างโดย `npm run setup`) ใส่ token หลัง `DISCORD_TOKEN=` (ไม่ใส่ `ANTHROPIC_API_KEY` ก็อ่านรูปได้ด้วยระบบอ่านฟรี)
4. `npm run dev` แล้วพิมพ์ `/setup` ในห้องส่งผล เลือกยศแอดมิน (และห้องประกาศผลถ้าต้องการ)

| คำสั่ง | ทำอะไร |
| --- | --- |
| `/setup` | ตั้งห้องส่งผล ยศแอดมิน ทัวร์นาเมนต์ (ไม่เลือก = รายการที่กำลังแข่ง) และห้องประกาศผล |
| `/setup-off` | หยุดอ่านผลในห้องนี้ หรือปิดการประกาศผล |
| `/rank` `/players` | Ranking ทีม / ผู้เล่น |
| `/team` `/player` | ข้อมูลทีม / สถิติผู้เล่น (พิมพ์ชื่อแล้วเลือกได้) |
| `/matches` | ผลล่าสุด |
| `/position` | ตั้งตำแหน่งของตัวเอง (Guard การ์ด บอลหลัก, Forward ฟอร์เวิร์ด บอลรอง, Center เซ็นเตอร์, All Around) ขึ้นที่หน้าทีมและหน้าผู้เล่นบนเว็บด้วย (ต้องผูกตัวละครกับ Discord ที่เว็บก่อน) |
| คลิกขวาที่โพสต์ → Apps → **อ่านผลจากโพสต์นี้** | อ่านโพสต์เก่าหรือโพสต์จากห้องอื่น |

ผลใหม่ทุกรายการ (ทั้งจาก Discord และจากหน้าเว็บ) จะถูกประกาศในห้องประกาศผลภายใน 1 นาที `SITE_URL` ใน `apps/bot/.env` คือที่อยู่เว็บที่ใช้ทำลิงก์ (ถ้าเป็นโดเมนจริง ลิงก์จะกดได้ใน Discord)

## บอท Discord: จัดทัวร์นาเมนต์ (แบบ Challonge)

รองรับ **Single Elimination**, **Double Elimination** และ **Round Robin** บอทต้องมีสิทธิ์เพิ่ม **Manage Channels**, **Manage Roles**, **Connect** และ **Speak** เพื่อสร้างห้องแชทและห้องเสียงที่เห็นเฉพาะ 2 ทีม (กับผู้จัด) ลิงก์เชิญที่ให้สิทธิ์ครบ (เปลี่ยน `APP_ID`):
`https://discord.com/oauth2/authorize?client_id=APP_ID&scope=bot+applications.commands&permissions=305253968`

1. `/tour create` ตั้งชื่อ รูปแบบ เวลาเริ่ม (เช่น `12/10 19:00` เวลาไทย) Best of (และ `final_best_of` ให้รอบชิงแข่งยาวกว่ารอบอื่นได้) เลทได้กี่นาที จำนวนผู้เล่นต่อทีม ยศผู้จัด และหมวดหมู่ที่จะสร้างห้องแข่ง
2. บอทโพสต์ประกาศรับสมัครพร้อมปุ่ม **สมัครทีม**: หัวหน้าทีมกดแล้วกรอกชื่อทีม จากนั้นเพิ่มผู้เล่นทีละคน (ช่องชื่อตัวละคร, UID, Server แยกกัน) แก้หรือลบรายคนได้ และเลือกเพื่อนร่วมทีมใน Discord ที่จะเข้าห้องแข่งได้ด้วย คนกดเป็นหัวหน้าทีม (`/register` ยังใช้ได้) เปิด/ปิดรับสมัครด้วย `/tour registration`
3. หัวหน้าทีมกด **จัดการทีมของฉัน** เพื่อแก้รายชื่อ โอนหัวหน้าทีม หรือถอนทีม ปุ่มพวกนี้เห็นเฉพาะหัวหน้าทีม ใช้ได้จนถึงเวลาแข่งของแมตช์แรก หลังจากนั้นล็อก (ผู้จัดยังแก้ได้บนเว็บ)
4. `/tour seed` จัดสายอัตโนมัติ (ตาม Ranking หรือสุ่ม) ปรับเองได้ด้วย `/tour swap` หรือบนเว็บ (หน้าแก้ไขทัวร์นาเมนต์ → จัดเอง) แล้วกด **ยืนยันและเริ่มแข่ง**
5. ทุกแมตช์ที่พร้อมจะได้ห้องแชท ห้องเสียงรวม และห้องเสียงเฉพาะของแต่ละทีม (ห้องทีมถูกลบเมื่อแมตช์จบ) มีรายชื่อทั้งสองทีม เวลาแข่ง และปุ่ม **เช็คอิน**, **ขอชนะบาย**, **แจ้งผู้จัด / แย้งผล**, **ผู้จัด**
6. แข่งจบแล้วกด 📸 **ส่งผลการแข่ง** ในห้องแข่ง เลือกทีมที่ชนะ ใส่สกอร์ และแนบรูปสกอร์บอร์ด บอทโพสต์รูปลงห้องแชทของคู่นั้นและอ่านสถิติให้ ชื่อผู้เล่นจะเอามาจากรายชื่อสองทีมในทัวร์เท่านั้น (ชื่อ + UID) ไม่สร้างผู้เล่นใหม่ ชื่อที่อ่านเพี้ยนจะจับคู่กับคนที่ชื่อใกล้ที่สุดในทีม (มีแท็กกิลด์นำหน้า เช่น OT_ ก็ได้) และฝั่งทีมดูจากรายชื่อ ถ้ารูปไหนชื่อแทบไม่ตรงกับทั้งสองทีม บอทจะเตือนว่าอาจเป็นรูปของเกมอื่น อีกทีม (หรือผู้จัด) กด **ยืนยันผล** แล้วผลกับสถิติขึ้นเว็บ ทีมชนะเข้ารอบถัดไปเอง (ถ้าอ่านรูปไม่ได้ จะบันทึกแค่สกอร์ที่แจ้ง)
7. แมตช์สุดท้ายมีผลแล้ว ทัวร์จบเองและบอทประกาศแชมป์ ถ้าจะจบก่อนแข่งครบ ผู้จัดกด 🛠️ **ผู้จัด** → 🏁 **จบทัวร์นาเมนต์** (หรือ `/tour end`) เลือกได้ว่าจะลบห้องแข่งเลยหรือเก็บไว้ ลบห้องทีหลังด้วย `/tour cleanup` (ถ้าทัวร์ยังไม่จบ ห้องของคู่ที่ยังไม่ได้แข่งจะถูกสร้างใหม่ บอทจึงให้จบทัวร์ก่อน)

ทัวร์ที่สร้างบนเว็บ: พิมพ์ `/tour link` ในห้องที่จะประกาศ แล้วเลือกทัวร์จากรายการ บอทจะโพสต์ประกาศรับสมัคร (หรือปุ่มลงชื่อเดี่ยวถ้าเป็นทัวร์ SOLO) และใช้คำสั่ง `/tour` อื่นกับทัวร์นี้ได้เหมือนสร้างจาก Discord สั่งซ้ำในห้องอื่นเพื่อย้ายประกาศได้

ลบทัวร์บนเว็บ (หลังบ้าน > ทัวร์นาเมนต์): ภายในครึ่งนาที บอทจะลบประกาศรับสมัคร ห้องแข่ง ห้องเสียง และหมวดที่บอทสร้างให้ด้วย แล้วโพสต์แจ้งในห้องประกาศ (ทัวร์ที่จบแล้วบอทจะเช็คทุก 5 นาที)

ชนะบาย: ถ้าเลยเวลาแข่ง + เวลาเลทแล้วอีกทีมยังไม่เช็คอิน ทีมที่เช็คอินแล้วกด **ขอชนะบาย** ได้ทันที ถ้าอีกทีมแย้ง ผู้จัดกด **ผู้จัด** เพื่อให้ทีมไหนชนะ หรือยกเลิกผลให้แข่งใหม่ (`/tour winner`, `/tour reopen` ก็ได้) ตั้งเวลาแข่งด้วย `/tour schedule` ดูสายด้วย `/tour bracket`

### ทัวร์ลงเดี่ยวผ่าน Discord

`/tour create` แล้วเลือก `entry: ลงเดี่ยว แล้วสุ่มจัดทีม (SOLO)` (ตั้ง `team_size` ได้ ค่าเริ่มต้น 3 คน) บอทจะโพสต์ประกาศที่มีปุ่ม:
- **🙋 ลงชื่อเดี่ยว / แก้ไข:** ผู้เล่นเลือกตำแหน่ง (Guard, Forward, Center, All Around) และแรงค์ในเกม ครั้งแรกให้ใส่ชื่อตัวละคร UID และ Server ด้วย กดอีกครั้งเพื่อแก้ไข
- **🚪 ถอนชื่อ:** ใช้ได้จนกว่าผู้จัดจะสุ่มทีม
- **🎲 สุ่มทีม (ผู้จัด):** ผู้จัดเห็นผลสุ่มคนเดียว กดสุ่มใหม่ได้จนพอใจ แล้วกด ✅ ยืนยัน บอทจะประกาศทีมพร้อมแท็กผู้เล่น

หลังยืนยันทีม ให้จัดสายด้วย `/tour seed` แล้วแข่งตามปกติ ห้องแข่งเปิดให้ผู้เล่นในทีมเข้าได้เลย ผู้เล่นจะลงชื่อที่หน้าเว็บของทัวร์ก็ได้ รายชื่อเป็นชุดเดียวกัน

### ตัวสำรอง รายการเล่นเก่งปากเก่ง (MMR แยก)

ห้องลงชื่อนี้เปิดรับตลอด ใช้ได้ทุกงาน รายชื่อเก็บบนเว็บ (หน้า `/special` และหลังบ้าน > ตัวสำรอง เล่นเก่งปากเก่ง)

**แต่ละเกมแยกกันทั้งหมด** (รายชื่อตัวสำรอง อันดับ MMR สถิติ และงาน) เพราะ UID และชื่อในแต่ละเกมไม่เหมือนกัน หน้า `/special` และหน้าแอดมินมีแท็บเลือกเกม ผู้เล่นลงได้ 1 ตัวละครต่อเกม

1. แอดมินพิมพ์ `/pool setup` เลือกห้องลงชื่อ, `game:` เกมของห้องนี้ (ทำ 1 ห้องต่อเกม แยกเซิร์ฟเวอร์ได้) และยศผู้จัด แรงค์ที่ให้เลือกคือแรงค์ของเกม ชุดเดียวกับรายการ Solo (หลังบ้าน > **เกม** > ปุ่ม **แรงค์**)
2. ผู้เล่นกด **ลงชื่อ / แก้ข้อมูล** กรอกชื่อตัวละคร, UID, Facebook, เบอร์โทร (ไม่ใส่ก็ได้) และตำแหน่ง บอลหลัก / บอลรอง / เซนเตอร์ / All Around แล้ว **ต้องเลือกแรงค์** ระบบจึงบันทึก หรือกดปุ่ม **📝 ลงชื่อตัวสำรอง** ในหน้า `/special` บนเว็บ แล้วกรอกฟอร์มเดียวกัน (รวมแรงค์) ที่หน้า "โปรไฟล์ของฉัน"
3. Facebook และเบอร์เห็นเฉพาะผู้จัด (`/pool list` และหน้าหลังบ้าน) หน้าเว็บสาธารณะไม่แสดง
4. ผู้จัดพิมพ์ `/pool draw count:4 rank:โซน position:CENTER player_a:@A player_b:@B` (rank และ position ไม่ใส่ก็ได้ All Around ถูกสุ่มได้ทุกตำแหน่ง) คนที่ไม่สะดวกกด **ไม่สะดวก** บอทสุ่มคนใหม่แทน ผู้จัดเปลี่ยนตัว สุ่มใหม่ ยืนยัน หรือยกเลิกได้
5. ทัวร์ที่ติ๊ก **รายการพิเศษ เล่นเก่งปากเก่ง** (หรือ `/tour create special:True`) ผลการแข่งไปที่ MMR และสถิติแยก เริ่ม 1000 ไม่รวมกับ Ranking หลักและเรตติ้งทีม ดูอันดับด้วย `/pool rank` หรือหน้า `/special`
6. เอาคนออกด้วย `/pool remove` รายชื่อเดิมใน Discord ถูกย้ายขึ้นเว็บเองตอนบอทเริ่มใช้งาน (คนเก่ากรอก Facebook และตำแหน่งเพิ่มตอนกดแก้ข้อมูล)

### ซีซั่น เล่นเก่งปากเก่ง

1. หลังบ้าน > **ซีซั่น เล่นเก่งปากเก่ง** สร้างซีซั่น (ชื่อ เกม วันเริ่ม-จบ) แล้ววางรายชื่อบรรทัดละคน `ชื่อ UID` (ก๊อปจาก Excel ได้) UID ที่มีในระบบแล้วจะผูกกับคนเดิม UID ใหม่จะสร้างผู้เล่นให้ บรรทัดที่ไม่มี UID จะแจ้งว่าเพิ่มไม่ได้
2. ตอนสร้างทัวร์ ติ๊ก **รายการพิเศษ** แล้วเลือกซีซั่น (หรือ `/tour create season:`) ทัวร์นั้นรับสมัครและใส่รายชื่อได้เฉพาะคนที่มีชื่อในซีซั่น ผู้จัดก็ต้องเพิ่มชื่อเข้าซีซั่นก่อน
3. **ผู้จัดจัดทีมเอง**: หลังบ้าน > หน้าแก้ไขทัวร์นาเมนต์ > **จัดทีมจากรายชื่อ** ติ๊กเลือกผู้เล่นจากรายชื่อซีซั่น (ถ้าทัวร์มีซีซั่น) หรือรายชื่อตัวสำรองของเกม กรองตามตำแหน่งและแรงค์ได้ ชื่อ UID และ Discord มาให้เอง ไม่ต้องพิมพ์ ในตัวแก้รายชื่อทีมก็มีช่อง "เพิ่มจากรายชื่อ" ใน Discord ใช้ `/tour addteam` (ช่อง pick1-pick5 พิมพ์ชื่อ UID ตำแหน่ง หรือแรงค์เพื่อค้นหา คนที่อยู่ทีมอื่นแล้วจะไม่ขึ้นให้เลือก)
4. MMR เล่นเก่งปากเก่งไม่รีเซ็ตตอนขึ้นซีซั่นใหม่ สะสมต่อจากซีซั่นก่อน หน้า `/special` เลือกดูทีละซีซั่นได้ (อันดับของคนในซีซั่น สถิติและงานของซีซั่นนั้น) หรือ **ทุกซีซั่น**
4. Discord: `/season list`, `/season players`, และสำหรับผู้จัด `/season create`, `/season add players:Kite 81000108; Lynx 7730586`, `/season remove`

## ทายผล (เหรียญฟรี)

ผู้ชมทายว่าใครชนะแต่ละคู่และใครได้แชมป์ ด้วยเหรียญฟรีที่ซื้อ ขาย หรือแลกเป็นเงินไม่ได้ (ไม่มีการจ่ายเงินเพื่อเล่น) รางวัลแจกตามอันดับบนตาราง ไม่มีการสุ่ม

- **ได้เหรียญ**: เล่นครั้งแรก 100 เหรียญ, กดรับวันละ 20 เหรียญ (เข้าต่อเนื่องได้เพิ่มวันละ 2 สูงสุด +10), เปิดเว็บไว้ตอนมีการแข่งสด ได้ 2 เหรียญทุก 5 นาที (วันละไม่เกิน 10 ครั้ง) ตัวเลขทั้งหมดแก้ได้ที่ `COINS` ใน `apps/api/src/lib/predict.ts`
- **ทาย**: แต่ละคู่เปิดทายเมื่อรู้ทั้งสองทีมและตั้งเวลาแข่งแล้ว ปิดเมื่อถึงเวลาแข่ง
- **ทายรายเกม**: คู่ที่แข่ง BO3 ขึ้นไป ทายผลแต่ละเกมแยกได้ (BO3 = 3 ครั้ง, BO5 = 5 ครั้ง) แต่ละเกมแบ่งเหรียญแยกกัน เปิดและปิดพร้อมคู่นั้น ผลมาจากคะแนนรายเกมที่บันทึก เกมที่ไม่ได้แข่ง (เช่นจบ 3-0 ใน BO5) หรือบันทึกผลแบบไม่มีคะแนนรายเกม คืนเหรียญ บนเว็บอยู่ใต้การ์ดของคู่นั้น ใน Discord กดปุ่ม 🎯 **ทายรายเกม** ที่การ์ด แชมป์ทายได้ตั้งแต่มีทีมสมัคร 2 ทีมจนเริ่มแข่ง เปลี่ยนหรือยกเลิกได้ก่อนปิด ผู้เล่นทายแมตช์ของทีมตัวเองหรือแชมป์รายการที่ตัวเองลงไม่ได้
- **ผล**: คนทายถูกได้เหรียญคืนพร้อมส่วนแบ่งของฝั่งที่ทายผิดตามสัดส่วนที่ลง ชนะบาย ชนะเพราะอีกฝั่งไม่มา ไม่มีใครทายถูก หรือรายการถูกลบ คืนเหรียญทุกคน ถ้าผู้จัดแก้ผลหรือยกเลิกผล เหรียญจะถูกปรับตามอัตโนมัติ
- **Overlay บนไลฟ์ (vMix / OBS)**: หลังบ้าน > ทายผล · รางวัล > **Overlay ทายผลบนไลฟ์** กดก๊อปลิงก์ (`/overlay/predict`) ไปใส่เป็น Web Browser input ใน vMix หรือ Browser Source ใน OBS ขนาด 1920×1080 พื้นหลังโปร่งใส โชว์สัดส่วนเหรียญสองฝั่ง จำนวนคน ผลตอบแทนต่อฝั่งแบบ Twitch (เช่นฝั่ง A 100 ฝั่ง B 1,000 → A ได้ x11 · B ได้ x1.1) นับถอยหลังปิดทาย ตราปิดรับคำทาย และผลพร้อมคนได้มากสุด อัปเดตทุก 2.5 วินาที ตามคู่ที่เปิดทายอยู่ให้เอง ตัวเลือก `?t=` ล็อกรายการ, `?m=W1-0` ล็อกคู่ (`W1-0#2` = เกม 2), `?pos=top`, `?scale=0.8`, `?preview=1` ตัวเลขทดลองไว้จัดตำแหน่ง
- **อันดับ**: ต่อรายการและต่อซีซั่นเล่นเก่งปากเก่ง (เหรียญที่ได้สุทธิ) และเหรียญรวม ดูที่ `/predict` และ `/predict board` ใน Discord
- **รางวัล**: หลังบ้าน > **ทายผล · รางวัล** วางโค้ดคูปองที่สร้างจากหลังบ้านร้าน Overtimeboosboos เป็นกลุ่ม (เช่น "ส่วนลด 50 บาท") แล้วแจกให้อันดับที่เลือกของรายการหรือซีซั่น (เฉพาะคนที่ได้เหรียญเป็นบวก) หรือให้ Discord ID คนเดียว ของรางวัลอย่างอุปกรณ์เกมมิ่งเลือกประเภท "ของรางวัล" แล้วติดตามสถานะ รอส่ง/ส่งแล้ว/ได้รับแล้ว เว็บไม่เก็บที่อยู่ ให้คุยทาง DM
- ผู้ได้รางวัลเห็นโค้ดที่หน้า **โปรไฟล์ของฉัน** และบอทส่ง DM ให้ หน้าหลังบ้านไม่แสดงโค้ด
- **Discord**: บอทโพสต์การ์ดทายผลในห้องประกาศ (ของทัวร์ที่บอทจัด หรือห้องประกาศผลจาก `/setup`) มีปุ่มชื่อทีม กดแล้วใส่จำนวนเหรียญ การ์ดอัปเดตสัดส่วนเหรียญและปิดพร้อมผล คู่ BO3/BO5 มีปุ่ม 🎯 ทายรายเกม คำสั่ง `/coins` รับเหรียญประจำวัน, `/predict board`, `/predict me`, `/predict open`

## เชื่อมกับเว็บไซต์อื่น

1. เข้า `/admin/keys` สร้าง key แบบ "อ่านอย่างเดียว"
2. เรียก API โดยส่ง key ใน header `X-API-Key`

```bash
curl -H "X-API-Key: trk_..." http://localhost:4000/api/v1/rankings/teams
```

```js
// ตัวอย่างฝั่งเซิร์ฟเวอร์ของเว็บคุณ (อย่าใส่ key ในโค้ดฝั่งเบราว์เซอร์)
const res = await fetch("https://api.your-domain.com/api/v1/rankings/teams?limit=10", {
  headers: { "X-API-Key": process.env.TOURNAMENT_API_KEY },
});
const { data } = await res.json(); // [{ rank, name, rating, stats: { wins, losses, ... } }, ...]
```

endpoint หลัก: `/api/v1/games`, `/api/v1/rankings/mmr` (ใส่ `?gameId=` เพื่อดูเฉพาะเกม), `/api/v1/rankings/teams`, `/api/v1/rankings/players`, `/api/v1/players/uid/{uid}`, `/api/v1/teams`, `/api/v1/players`, `/api/v1/tournaments`, `/api/v1/matches`, `/api/v1/stats/overview`, `/api/v1/stats/search` ดูทั้งหมดพร้อมทดลองยิงได้ที่ `/docs` (ไฟล์ spec: `apps/api/openapi.yaml`)

- key แบบ `read` ใช้ได้เฉพาะ GET ส่วน `admin` เพิ่ม/แก้/ลบได้
- ถ้าจะเรียกจากเบราว์เซอร์โดยตรง ให้ใส่โดเมนเว็บนั้นใน `CORS_ORIGINS` ของ `apps/api/.env`
- สร้าง key จาก command line ได้ด้วย: `npm run key:create -w apps/api -- "ชื่อเว็บ" read`

## การตั้งค่า

`apps/api/.env`

| ตัวแปร | ความหมาย |
| --- | --- |
| `DATABASE_URL` | ฐานข้อมูล (ค่าเริ่มต้น SQLite `file:./dev.db`) |
| `PORT` | พอร์ตของ API (4000) |
| `CORS_ORIGINS` | โดเมนที่เรียก API จากเบราว์เซอร์ได้ คั่นด้วย `,` |
| `UPLOAD_DIR` | โฟลเดอร์เก็บรูปที่อัปโหลด (ค่าเริ่มต้น `uploads`) |
| `ANTHROPIC_API_KEY` | ไม่บังคับ ใส่เพื่อให้ AI อ่านผลจากรูปแทนระบบอ่านฟรี (แม่นกว่ากับรูปเล็กหรือไม่ชัด) |
| `ANTHROPIC_MODEL` | โมเดลที่ใช้อ่านรูป (ไม่ใส่ = `claude-haiku-5-5` ถูกที่สุด) ถ้าอ่านพลาดบ่อย ลอง `claude-sonnet-5-5` หรือ `claude-opus-5-5` |

`apps/web/.env.local` (สร้างให้อัตโนมัติโดย `npm run setup`)

| ตัวแปร | ความหมาย |
| --- | --- |
| `API_URL` | ที่อยู่ API ที่เว็บเรียก |
| `API_KEY` | API key สิทธิ์ admin ใช้ฝั่งเซิร์ฟเวอร์เท่านั้น |
| `ADMIN_PASSWORD` | รหัสผ่านเข้า `/admin` |

| `PUBLIC_API_URL` | ที่อยู่ API สาธารณะสำหรับลิงก์เอกสาร (ถ้าต่างจาก `API_URL`) |

## ระบบป้องกัน

- หน้าเข้าสู่ระบบหลังบ้านซ่อนได้ด้วย `ADMIN_PATH` และใส่รหัสผิด 5 ครั้งจากที่อยู่เดียวกัน จะล็อก 15 นาที
- API ทุกเส้นต้องใช้ API key คีย์อ่านอย่างเดียวแก้ข้อมูลไม่ได้ คำขอจากอินเทอร์เน็ต (ผ่าน Cloudflare) ถูกจำกัด 600 ครั้งต่อนาทีต่อที่อยู่ และใส่คีย์ผิด 20 ครั้งใน 10 นาทีจะถูกพัก เว็บและบอทที่รันบนเครื่องเดียวกันไม่ถูกจำกัด
- ทุกหน้าส่ง security headers: ห้ามฝังในเว็บอื่น (กัน clickjacking), ห้ามเดาชนิดไฟล์, ใช้ https เสมอ, ปิดกล้อง/ไมค์/ตำแหน่ง
- ทายผล: เหรียญทุกการเปลี่ยนแปลงมีบันทึก (ledger) ทำทีละรายการจึงกดซ้ำแล้วใช้เหรียญซ้ำไม่ได้ เช็กเวลาปิดทายที่เซิร์ฟเวอร์ คนอื่นเห็นแค่สัดส่วนรวม ไม่เห็นว่าใครทายอะไร โค้ดรางวัลเห็นเฉพาะเจ้าของ
- คุกกี้ล็อกอินเป็น httpOnly และ sameSite ลงชื่อด้วย `SESSION_SECRET` อัปโหลดรับเฉพาะรูป PNG, JPG, WebP, GIF ไม่เกิน 8 MB
